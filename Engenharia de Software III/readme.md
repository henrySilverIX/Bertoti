# O que é padrão de projetos?
R: Um padrão de projetos é uma solução reutilizável para problemas comuns nos projetos de software. Uma solução reutilizável é uma solução já testada e comprovada que pode ser aplicada em outros problemas. 


# O que é um anti-padrão de projetos?
R: Um anti-padrão de projetos ou solução anti-padrão de projetos é uma solução comum ao um problema que a primeira vista parece ser boa, mas que a longo prazo se mostra ineficiente ou contraproducente.

# O que é um padrão de projetos Strategy?
R:O padrão de projetos Strategy é um padrão de projetos que permite que você defina uma família de algoritmos, coloque-os em classes separadas e faz os seus objetos serem intercambiáveis.


# O que é um anti-padrão de projetos Strategy?
R: Um anti-padrão de projetos Strategy ocorre quando não há uma divisão em classes separadas dos algoritmos, fazendo com o que o código seja ineficiente e muito trabalhoso de fazer qualquer manutenção.
